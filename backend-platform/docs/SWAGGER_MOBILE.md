# Mobile Panel Swagger

The Mobile Panel API documentation is available when the auth service is running.

## Swagger UI

Open [http://localhost:8080/swagger-mobile.html](http://localhost:8080/swagger-mobile.html) to launch the Mobile Swagger UI.

## OpenAPI JSON

The Mobile Panel OpenAPI specification is available at:

`http://localhost:8080/v3/api-docs/mobile`

## Included APIs

- Login, sign-up, token refresh, and password reset
- Product catalogue and categories
- Orders
- Customer profile and addresses
- Health check

## Authorization

Public endpoints can be called directly. For protected endpoints, select **Authorize** in Swagger UI and enter the access token as a bearer token.
